# Applied AI Learning and Assurance

This folder turns the referenced AI courses into a practical program for building and governing real systems. The work is applied first to Sentinel, then reused for Island Leads, VIVCO Signal, Terra Mobi Systems, KandaSokoni, and Afuopulse.

## Start here

1. Follow [LEARNING_PLAN.md](./LEARNING_PLAN.md).
2. Build the exercises in [PROJECT_LABS.md](./PROJECT_LABS.md).
3. Record results in [PROGRESS_LOG.md](./PROGRESS_LOG.md).
4. Before any AI feature is released, complete:
   - [AI_EVALUATION.md](./AI_EVALUATION.md)
   - [SECURITY_EVALUATION.md](./SECURITY_EVALUATION.md)
   - [GOVERNANCE_CHECKS.md](./GOVERNANCE_CHECKS.md)

## Working rule

Do not complete courses passively. For every lesson:

1. Run one example.
2. Change one important assumption.
3. Apply the idea to a real venture.
4. Test expected and abusive behavior.
5. Record what worked, what failed, and the evidence.
6. Commit the result to GitHub without secrets or personal data.
