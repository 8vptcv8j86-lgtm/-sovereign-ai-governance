# NITDA validation outreach draft

Director General Inuwa's emphasis on converting policy requirements into contracted demand identifies an important implementation question: how institutions will prove that proposed cloud and sovereign AI services meet those requirements in operation.

Sentinel translates data residency, provider dependency, auditability, authorization, continuity, portability and exit requirements into testable controls and an exportable institutional evidence package.

We would value a technical validation conversation with the appropriate NITDA infrastructure, cloud or AI governance team. The proposed scope is deliberately narrow: one institution, one AI or cloud enabled system and one evidence package. The purpose is to test whether the control framework reflects Nigeria's procurement and sovereign infrastructure priorities. It is not a request for endorsement or a claim of regulatory approval.
