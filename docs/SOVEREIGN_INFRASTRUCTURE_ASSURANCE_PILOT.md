# Sentinel Sovereign Infrastructure Assurance pilot

## Purpose

Translate infrastructure, cloud and sovereign AI policy requirements into tested procurement controls and an exportable evidence package.

## Pilot boundary

- One institution
- One AI or cloud enabled system
- One accountable executive
- One primary provider and its critical subprocessors
- One complete evidence package

## Work performed

1. Register the system, provider, hosting location, data categories and decision impact.
2. Test deployment authorization, human control, incident response and shutdown authority.
3. Assess data residency, provider concentration, portability, contractual audit rights and exit readiness.
4. Review backup method, recovery targets, fallback capacity and evidence from the latest restoration exercise.
5. Verify the institutional audit chain and authorization history.
6. Produce a clear outcome: ready, conditional approval or blocked.
7. Export the complete assurance package with unresolved findings, owners and remediation dates.

## Pilot deliverables

- Sovereign Infrastructure Assurance assessment
- Failed control register
- Data residency and dependency map
- Recovery and exit readiness record
- Authorization and audit integrity evidence
- Procurement conditions and remediation plan
- Versioned governance evidence package

## Proposed validation request

Sentinel is seeking one Nigerian institution or infrastructure provider willing to test this assurance method against one real deployment. The pilot is intended to validate the control framework and evidence workflow. It is not a regulatory certification or a claim of government endorsement.
